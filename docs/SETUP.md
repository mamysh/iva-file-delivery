# Установка и обновление

## Перед установкой

Убедитесь, что Ива уже получает сообщения в личном чате и отвечает через своего Telegram-бота.
Плагин проверен с Iva `0.4.3`. С Iva `0.4.6` живую проверку пока не проводили. Новый токен бота
создавать не нужно.

Все команды ниже выполняйте на сервере под тем же пользователем, что и Иву.

## Установить

```bash
iva plugin add mamysh/iva-file-delivery/plugin@stable --trust
iva plugin list
iva doctor
```

Ива соберёт плагин и перезапустится. Флаг `--trust` разрешает отдельный процесс, который
проверяет и применяет обновления из чата. Без этого флага отправка файлов работает, а
обновление из чата недоступно. Включить его позже можно командой
`iva plugin trust file-delivery`.

`stable` указывает на последний выпущенный tag. Если хотите закрепить одну версию, укажите
`@v0.3.1` вместо `@stable`. Для перехода с одного tag на другой потребуется удалить плагин и
установить его снова. Созданные файлы при удалении остаются на диске.

## Проверить отправку

Напишите Иве в личном чате:

> Создай небольшой текстовый файл с фразой «Проверка доставки» и пришли его сюда как файл.

Файл должен прийти от имени бота. Затем попросите создать два небольших файла разных
форматов и прислать их вместе. Они должны появиться одной группой. Для проверки используйте
только вымышленные данные.

## Обновить из чата

Напишите: «Проверь обновление плагина доставки файлов». Ива покажет текущую и новую версии,
результат проверки GitHub Actions и список изменений. Если список не загрузился, карточка
даст ссылку на `CHANGELOG.md` нужной версии. Для запуска обновления нажмите **Обновить**.

Обновление выполняется в отдельном процессе и может ненадолго перезапустить Иву. Через
минуту спросите: «Как прошла обнова плагина доставки файлов?». Если проверка после установки
не пройдёт, плагин попытается вернуть предыдущую версию.

Если кнопка обновления недоступна, можно обновить плагин из терминала:

```bash
iva plugin update file-delivery
iva doctor
```

Эта команда работает для установки из `@stable`. Установка по tag закреплена за конкретным
выпуском. Для смены источника удалите плагин и установите его заново. Данные самого плагина
Ива сохраняет по своим правилам.

### Переход с 0.1.x

В версии `0.1.x` ещё нет обновления из чата. Один раз выполните в терминале:

```bash
iva plugin update file-delivery
iva plugin trust file-delivery
iva doctor
```

После этого следующие обновления можно подтверждать в чате.

## Отключить или удалить

```bash
iva plugin disable file-delivery
iva plugin remove file-delivery
iva doctor
```

Удаление не стирает файлы в `vault/attachments/`. Если они больше не нужны, удалите их
отдельно.

## Если что-то не работает

| Сообщение | Что проверить |
| --- | --- |
| `Telegram bot is not configured` | Работает ли Telegram-бот самой Ивы. Отдельный файл с токеном для плагина не нужен. |
| `file delivery requires an authenticated user turn` | Запрос должен прийти от владельца в Telegram, а не из терминала или фоновой задачи. |
| `file delivery is allowed only in the owner's current private Telegram chat` | Откройте личный чат с ботом; группы и чужие чаты не поддерживаются. |
| `path must be relative to vault/attachments` | Ива передала абсолютный путь. Файл должен лежать внутри `vault/attachments/`. |
| `attachment is unavailable` | Убедитесь, что файл уже создан и доступен Иве. |
| `Telegram rejected the upload` или `Telegram rejected the album` | Проверьте соединение и размер каждого файла; инструмент вернёт только HTTP-статус. |
| `enabled · untrusted` | Отправка работает, но обновление из чата выключено. Запустите `iva plugin trust file-delivery`. |
| `UPDATE_CHECK_REQUIRED` или `UPDATE_OFFER_EXPIRED` | Заново попросите Иву проверить обновление и используйте новую кнопку. |
| `CI_NOT_SUCCESSFUL` | Дождитесь успешной проверки выпуска на GitHub. |
| `rolled_back` | Предыдущая версия восстановлена. Дальше обновляйте из терминала после выяснения причины. |

Если сообщаете об ошибке публично, укажите версии и шаги воспроизведения с вымышленными
данными. Не публикуйте токен бота, содержимое файлов, полные журналы Ивы и пути на сервере.
