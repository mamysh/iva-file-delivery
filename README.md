# Отправка файлов из Ивы в Telegram

Плагин помогает [Иве](https://github.com/smixs/iva-agent) присылать готовые файлы в ваш личный
Telegram-чат. Файлы приходят от имени бота Ивы. Если за одну задачу получилось несколько
файлов, Ива отправит их вместе, даже если форматы разные.

[![CI](https://github.com/mamysh/iva-file-delivery/actions/workflows/ci.yml/badge.svg)](https://github.com/mamysh/iva-file-delivery/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## Установка

Понадобится работающая Ива с Telegram-ботом. Плагин проверен с Iva `0.4.3`; совместимость с
вышедшей позже `0.4.6` ещё не проверена на живой установке. Команды запускайте на сервере под
тем же пользователем, что и Иву:

```bash
iva plugin add mamysh/iva-file-delivery/plugin@stable --trust
iva plugin list
iva doctor
```

`--trust` разрешает плагину запускать отдельный процесс для обновлений из чата. Если эта
возможность не нужна, уберите флаг: отправка файлов продолжит работать. Новый токен Telegram
и отдельный `.env` не нужны. Подробнее об установке и ошибках - в [инструкции](docs/SETUP.md).

## Проверка

Напишите Иве в личном чате:

> Создай небольшой текстовый файл с фразой «Проверка доставки» и пришли его сюда как файл.

Документ должен появиться от имени бота Ивы. Затем попробуйте попросить два файла разных
форматов: они должны прийти одной группой. Для проверки используйте вымышленные данные.

## Что умеет плагин

- Отправляет один файл или группу от 2 до 10 файлов. Если файлов больше, Ива отправляет
  несколько групп.
- Принимает файлы разных форматов в одной группе. Все они приходят как документы, без
  превращения картинок в фотографии или аудио в голосовые сообщения.
- Отправляет файлы только владельцу в том личном чате, откуда пришёл запрос. Путь к файлу
  должен находиться внутри `vault/attachments/`. Каждый файл должен быть непустым и не больше
  50 МБ.
- Позволяет проверить обновление из чата и подтвердить его кнопкой. Перед подтверждением
  показывает список изменений из `CHANGELOG.md`, если он доступен.

Плагин не отправляет файлы в группы, каналы или по расписанию. Он не проверяет содержимое на
секреты: прежде чем попросить Иву прислать чувствительный файл, проверьте, что в нём.
Больше об ограничениях и защите данных - в [SECURITY.md](SECURITY.md).

## Обновление

Попросите Иву: «Проверь обновление плагина доставки файлов». Она покажет версии и изменения,
а затем предложит кнопки **Обновить** и **Позже**. При установке с `@stable` будут доступны
следующие проверенные выпуски. Для установки неизменяемой версии вместо `@stable` укажите
точный tag, например `@v0.3.1`.

Ветка `main` содержит разработку, а `stable` указывает на последний выпущенный tag. Инструкции
для ручного обновления, удаления и устранения ошибок находятся в [docs/SETUP.md](docs/SETUP.md).

## Для разработчиков

Код отправки работает как Eve Extension, а обновление из чата - как отдельный MCP-процесс.
Обычный текст ответа Ивы идёт штатным путём. Исходники и технические детали описаны в
[docs/DESIGN.md](docs/DESIGN.md) и [docs/COMPATIBILITY.md](docs/COMPATIBILITY.md).

```bash
npm ci
npm run check
```
