# Contributing

Спасибо за интерес к `iva-file-delivery`. Проект принимает исправления, тесты, улучшения
документации и предложения, сохраняющие узкую границу отправки файла владельцу текущего
личного Telegram-чата.

## Перед началом

1. Для ошибки создайте issue с минимальным синтетическим примером.
2. Для новой возможности опишите, зачем она нужна, какие данные добавляет в tool input/output
   и как влияет на получателя, файловую границу и приватность.
3. Не прикладывайте bot token, реальные chat/user ID, частные файлы, имена рабочих файлов,
   абсолютные пути, screenshots или несокращённые логи.

Запросы на произвольный `chat_id`, группы, каналы, userbot, публичный upload-host или чтение
за пределами `vault/attachments/` не соответствуют текущей модели проекта.

## Локальная проверка

Требуются Node.js 24 и npm:

```bash
npm ci
npm run check
```

Изменение tool-контракта или файловой политики должно включать положительные и отрицательные
тесты, обновление README, SECURITY и CHANGELOG. Используйте только временные каталоги и
синтетические данные.

## Pull request

- Делайте изменение небольшим и самостоятельным.
- Объясните влияние на разрешения, приватность и обратную совместимость.
- Не добавляйте новые сетевые назначения без отдельного security review.
- Убедитесь, что diff и вся история ветки не содержат секретов или локальных следов.
- Подтвердите прохождение `npm run check`.

Отправляя изменение, вы соглашаетесь лицензировать свой вклад на условиях MIT License этого
репозитория.
