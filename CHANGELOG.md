# Changelog

## 0.3.2 — 2026-10-04 (подготовка выпуска, ещё не выпущено)

- Исправлены сравнение версий с дефисами в prerelease-суффиксе и проверка числовых
  идентификаторов с ведущими нулями в updater; добавлены регрессионные тесты.
- Одиночная отправка и альбом используют общую обработку безопасных ошибок.
- Во вложенном lock-файле Extension также закреплён исправленный `undici` 8.11.2
  для Eve 0.51.1. Аудит проверяет оба lock-файла локально и в CI.
- Компилятор проверяет неиспользуемые переменные и параметры; проверка поставки
  отклоняет случайные копии файлов и каталогов с числовыми суффиксами.

## Пока не выпущено

- Главная страница построена вокруг запросов к Иве, получения файлов и первого запуска.
- Добавлены обложка, иллюстрация доставки, навигация по помощи и промпты для изображений.
- Возможности отправки и обновления плагина не изменились.
- Для сборки закреплена исправленная зависимость `undici` 8.11.2 внутри Eve 0.51.1.

## 0.3.1 — 2026-09-22

- Карточка обновления показывает изменения из `CHANGELOG.md` для всех новых версий после
  установленной. Если файл не загрузился, карточка даёт ссылку на него.
- Упрощены README и инструкция установки для пользователей Ивы: исправлены пример версии,
  подсказки об ошибках и описание проверенной совместимости.

## 0.3.0 — 2026-09-22

- Добавлена отправка 2–10 файлов одним Telegram-альбомом через `sendMediaGroup`.
  Форматы файлов могут различаться; все элементы отправляются как документы.
- Ива автоматически выбирает альбом, когда для одной задачи готово несколько файлов.
  Одиночная отправка через `sendDocument` сохранена.
- Все файлы альбома проверяются до сетевого запроса; ограничения личного чата и
  `vault/attachments/` действуют для каждого файла.

## 0.2.0 — 2026-09-19

- Добавлен такой же owner-confirmed update-flow, как в `iva-bitrix24`: проверка SemVer и
  GitHub Actions, нативные кнопки Iva, одноразовый offer token и отдельная systemd job.
- Worker обновляет только уже установленный `file-delivery`, сверяет точный SHA, запускает
  `iva doctor` и возвращает предыдущую версию при неуспешной диагностике.
- Добавлены три MCP-инструмента проверки, применения и статуса. Для них требуется один раз
  выполнить `iva plugin trust file-delivery`; Telegram token MCP-процессу не передаётся.
- Добавлены bundle smoke-test, worker tests и отрицательные тесты moving ref, CI и approval.

## 0.1.1 — 2026-09-19

- Добавлен lock-файл runtime-пакета: Iva теперь использует `npm ci`, а Zod не разрешается
  заново при каждой установке.
- Peer Eve зафиксирован на проверенной версии `0.51.1`; Iva по-прежнему предоставляет и
  использует собственную копию Eve при сборке Extension.

## 0.1.0 — 2026-09-19

- Первый публичный выпуск.
- Добавлен Telegram upload от имени бота через `sendDocument` и `multipart/form-data`.
- Назначение жёстко привязано к владельцу текущего личного чата; произвольный `chat_id`
  отсутствует.
- Источник ограничен обычными непустыми файлами внутри `vault/attachments/`; скрытые пути,
  симлинк-выходы и файлы больше 50 МБ отклоняются.
- Добавлены skill Ивы, отрицательные тесты, проверка дистрибутива и автоматический поиск
  секретов и локальных следов.
